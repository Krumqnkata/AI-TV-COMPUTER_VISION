# Архив

Файловете тук пазят исторически продуктови идеи и вече не са източник на текущи изисквания. Активният roadmap е root `TASK.md`, а работещата архитектура е описана в `README.md`.

`TASK-original.md` съдържа оригиналната разширена спецификация, включително дублирани и отложени идеи. Тя е запазена само за проследимост.
