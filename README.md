# 🛡️ School AI - Cyber HUD
### Интелигентна система за лицево разпознаване с футуристичен интерфейс и AI асистент

**School AI** е модерна система за компютърно зрение, проектирана за училищна среда. Тя съчетава силата на **MediaPipe** и **face_recognition** за прецизна идентификация, футуристичен графичен интерфейс (Cyber-HUD) и интелигентен гласов асистент, задвижван от **Gemini AI**.

---

## ✨ Основни възможности

*   **🚀 Cyber-HUD Интерфейс**: Динамичен оверлей в реално време с 1080p поддръжка, кирилски шрифтове и гладки анимации.
*   **🧠 AI Хумор (Gemini)**: Интеграция с най-новите модели на Google Gemini за генериране на уникални и забавни закачки за всеки разпознат ученик/учител.
*   **🗣️ Висококачествен Български Говор**: Използва **Piper TTS** за кристално чист и естествен български глас, работещ изцяло локално.
*   **📊 Дневен Брояч**: Автоматично следене и статистика на уникалните посещения за деня.
*   **🌐 Web Control Panel**: Мощен уеб интерфейс (FastAPI), позволяващ дистанционно управление, стрийминг на живо и управление на базата данни.
*   **⚡ Оптимизирана производителност**: Асинхронна обработка на кадри, CLAHE подобряване на изображението и кеширане на AI заявките за пестене на ресурси.

---

## 🛠️ Технологичен стек

*   **Python 3.10+**
*   **OpenCV**: Обработка на видео потока и HUD рендеринг.
*   **MediaPipe**: Бързо и точно засичане на лица.
*   **face_recognition (dlib)**: Високо прецизно разпознаване чрез 128D вектори.
*   **Google Gemini API**: Генеративен изкуствен интелект за персонализирани реплики.
*   **Piper TTS**: Локален синтез на реч (Bulgarian Dimitar model).
*   **FastAPI & Jinja2**: Уеб сървър и контролен панел.

## 📥 Инсталация

1.  **Клонирайте хранилището**:
    ```bash
    git clone <repository-url>
    cd AI-TV-COMPUTER_VISION
    ```

2.  **Създайте виртуална среда**:
    ```bash
    python -m venv .venv
    source .venv/bin/activate  # За Windows: .venv\Scripts\activate
    ```

3.  **Инсталирайте зависимостите**:
    ```bash
    pip install -r requirements.txt
    ```

4.  **Конфигурирайте системата**:
    *   Създайте `.env` файл в коренната директория.
    *   Добавете своя `GEMINI_API_KEY`.
    *   Настройте `CAMERA_SOURCE` (0 за уеб камера или RTSP URL).

---

## ⚙️ Конфигурация (.env)

| Променлива | Описание | Стойност по подразбиране |
| :--- | :--- | :--- |
| `GEMINI_API_KEY` | Вашият API ключ от Google AI Studio | (Задължително за AI шеги) |
| `CAMERA_SOURCE` | Индекс на камера или RTSP стрийм | `0` |
| `COOLDOWN_SECONDS` | Време за изчакване преди повторно поздравление | `30` |
| `TARGET_WIDTH` | Ширина на HUD интерфейса | `1920` |
| `TARGET_HEIGHT` | Височина на HUD интерфейса | `1080` |
| `PIPER_MODEL_PATH` | Път до българския гласов модел | `engine/piper/bg_BG-dimitar-medium.onnx` |

## 📂 Структура на проекта

*   `main.py` — Основен вход на програмата и HUD логика.
*   `engine/` — Ядрото на системата:
    *   `face_manager.py` — Управление на лицата и MediaPipe логика.
    *   `tts_manager.py` — Интеграция с Gemini и Piper TTS.
    *   `state_manager.py` — Глобално състояние и синхронизация с уеб панела.
*   `web/` — FastAPI сървър и шаблони за контролния панел.
*   `data/` — База данни със снимки, кеш и аудио файлове.
*   `utils/` — Конфигурации и логър.
